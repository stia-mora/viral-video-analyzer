# 实施与验收

## 应用范围

FastAPI + SQLite WAL 后端、React TypeScript 前端，同源部署。一个团队共享资料库；管理员创建成员、管理模型配置，成员提交与查看分析。密码哈希、HttpOnly 会话、写操作来源检查和资源鉴权。

队列持久化，单任务处理避免 GPU 抢占，服务重启恢复未完成任务。视频通过 yt-dlp 与抖音页面采集器获取；本地历史输出可导入。保存元数据、评论样本、媒体、时间戳转写、关键帧、结构化报告。支持本地 Qwen ASR 与兼容模型服务，失败保留已完成成果。

## 验收证据

- 原有 scripts/process_douyin_video.ps1 保留。
- 完整视频与封面下载需经过真实 HTTP 资源端点验证。
- 非管理员不能修改团队与模型配置，未登录不能读取视频。
- 缺失指标为 null，比例不在分母未知或零时计算。
- 报告包含开场钩子、结构、视觉证据、评论意图与可复用建议。
- 前端生产构建、后端测试、真实本地视频处理与浏览器桌面/手机验证。
- 启动脚本与部署说明，应用保持运行。
